# dilemma

[Play dilemma](https://moral-dilemma-c8435.web.app)

A simple game about difficult choices.

- Play solo or with friends in multiplayer rooms.
- Choose from multiple-choice responses and see global response percentages.
- Sign in or play multiplayer as a guest with any optional username. Guests who leave it blank receive names such as “Guest (1)” and “Guest (2)”; duplicate usernames are allowed.
- Use “Hide percentages” whenever you do not want the percentages displayed.
- Earn a point for choosing the group’s most common response; ties award everyone a point.
- See the final scoreboard.

For guest multiplayer, enable the Anonymous provider in Firebase Authentication → Sign-in method.
